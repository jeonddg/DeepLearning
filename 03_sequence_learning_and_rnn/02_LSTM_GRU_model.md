# 02. LSTM과 GRU 모델

이번에는 RNN의 발전 버전인 **LSTM**과 **GRU**를 공부한다.

이전 파일에서 RNN은 순서가 있는 데이터를 학습하기 위한 모델이라고 정리했다.
하지만 기본 RNN인 **Simple RNN**은 문장이 길어질수록 앞부분 정보를 잘 기억하지 못하는 문제가 있다.

그래서 이 문제를 해결하기 위해 등장한 모델이 LSTM과 GRU이다.

---

## 1. Simple RNN의 문제점

Simple RNN은 이전 hidden state를 다음 시점으로 넘기면서 순서를 기억한다.

예를 들어 문장을 단어 단위로 처리하면 다음과 같은 흐름이 된다.

```text
I -> went -> to -> the -> library -> to -> ____
```

RNN은 `I`를 읽고 나온 정보를 `went`를 처리할 때 사용한다.
그리고 `went`까지 읽고 나온 정보를 `to`를 처리할 때 사용한다.

이런 방식 덕분에 순서를 어느 정도 기억할 수 있다.

하지만 문장이 길어지면 문제가 생긴다.

처음에 나온 중요한 정보가 뒤로 갈수록 점점 약해질 수 있다.

```text
처음 정보: 100
다음 단계: 50
다음 단계: 25
다음 단계: 12.5
다음 단계: 6.25
...
```

이런 느낌으로 앞부분 정보의 영향력이 점점 줄어드는 것이다.

---

## 2. Diminishing Gradient란?

Simple RNN의 대표적인 문제는 **Diminishing Gradient**이다.

Diminishing Gradient는 한국어로 보통 **기울기 소실 문제**라고 부른다.

딥러닝 모델은 학습할 때 오차를 줄이는 방향으로 weight를 조금씩 수정한다.
이때 뒤쪽에서 계산된 오차 정보가 앞쪽 레이어나 앞쪽 시점까지 전달되어야 한다.

그런데 RNN에서는 sequence가 길어질수록 이 정보가 점점 작아질 수 있다.

그러면 모델은 문장의 뒷부분은 잘 반영하지만, 앞부분 정보는 거의 잊어버리게 된다.

예를 들어 영어 문장에서 주어와 동사가 멀리 떨어져 있으면 앞에 나온 주어 정보를 기억해야 한다.
하지만 Simple RNN은 문장이 길면 그 정보를 끝까지 유지하기 어렵다.

---

## 3. 그래서 LSTM이 등장했다

LSTM은 **Long Short-Term Memory**의 줄임말이다.

이름 그대로 해석하면 **긴 기억과 짧은 기억을 다루는 모델**이다.

LSTM은 Simple RNN보다 오래 기억할 수 있도록 설계된 RNN 계열 모델이다.

Simple RNN은 hidden state 하나에 많은 정보를 담으려고 한다.
반면 LSTM은 정보를 더 오래 보관하기 위해 **cell state**라는 길게 이어지는 기억 공간을 추가로 사용한다.

쉽게 말하면 다음과 같다.

```text
Simple RNN
- hidden state 하나로 기억을 처리함

LSTM
- hidden state + cell state를 사용함
- 중요한 정보는 오래 보관하고, 필요 없는 정보는 버릴 수 있음
```

---

## 4. LSTM의 핵심은 gate이다

LSTM은 정보를 무조건 다 기억하지 않는다.

대신 gate를 사용해서 다음을 결정한다.

```text
무엇을 버릴지
무엇을 새로 기억할지
무엇을 밖으로 출력할지
```

여기서 gate는 쉽게 말해 **정보가 지나갈지 말지 조절하는 문**이라고 생각하면 된다.

LSTM에는 대표적으로 세 가지 gate가 있다.

---

## 5. Forget Gate

Forget Gate는 **무엇을 잊을지 결정하는 문**이다.

문장을 읽다 보면 모든 단어를 똑같이 중요하게 기억할 필요는 없다.
어떤 정보는 다음 예측에 중요하고, 어떤 정보는 크게 중요하지 않다.

Forget Gate는 기존 cell state에서 필요 없는 정보를 줄이거나 버리는 역할을 한다.

예를 들어 문장에서 주제가 바뀌면 이전 주제와 관련된 정보는 덜 중요해질 수 있다.
이런 정보를 계속 들고 있으면 오히려 예측이 헷갈릴 수 있다.

그래서 LSTM은 Forget Gate를 통해 필요 없는 기억을 정리한다.

---

## 6. Input Gate

Input Gate는 **무엇을 새로 기억할지 결정하는 문**이다.

새로운 단어가 들어왔을 때, 그 단어의 정보를 cell state에 저장할지 말지 결정한다.

예를 들어 문장에서 중요한 명사, 동사, 감정 표현 같은 정보는 기억할 필요가 있다.
반대로 크게 중요하지 않은 단어는 약하게 반영해도 된다.

Input Gate는 새로 들어온 정보 중 중요한 것만 cell state에 추가하는 역할을 한다.

---

## 7. Output Gate

Output Gate는 **무엇을 출력할지 결정하는 문**이다.

LSTM 내부에는 cell state라는 기억 공간이 있다.
하지만 그 기억을 전부 밖으로 내보낼 필요는 없다.

Output Gate는 현재 시점에서 다음 레이어나 다음 시점에 넘길 정보를 결정한다.

즉, cell state에 저장된 기억 중에서 지금 필요한 정보만 hidden state로 내보내는 역할을 한다.

---

## 8. LSTM을 너무 수식으로 외울 필요는 없다

LSTM 내부 계산식은 꽤 복잡하다.

하지만 처음 공부할 때는 수식을 전부 외우는 것보다 역할을 먼저 이해하는 것이 중요하다.

핵심은 이것이다.

```text
Forget Gate: 필요 없는 정보는 버린다.
Input Gate: 새로 중요한 정보는 저장한다.
Output Gate: 지금 필요한 정보만 출력한다.
Cell State: 오래 들고 갈 기억을 저장한다.
Hidden State: 현재 시점의 출력 기억이다.
```

코드에서는 직접 gate를 하나하나 만들 필요가 없다.
TensorFlow에서는 아래처럼 레이어를 사용하면 된다.

```python
tf.keras.layers.LSTM(64)
```

즉, 내부 구조는 복잡하지만 코드에서는 `LSTM()` 레이어 하나로 사용할 수 있다.

---

## 9. GRU란?

GRU는 **Gated Recurrent Unit**의 줄임말이다.

GRU도 LSTM처럼 Simple RNN의 기억력 문제를 보완하기 위해 만들어진 모델이다.

다만 LSTM보다 구조가 조금 더 간단하다.

LSTM은 cell state와 여러 gate를 사용한다.
GRU는 구조를 줄여서 더 빠르고 가볍게 동작하도록 만든 모델이다.

쉽게 비교하면 다음과 같다.

```text
LSTM
- 구조가 더 복잡함
- 기억을 세밀하게 조절함
- 학습 시간이 더 걸릴 수 있음

GRU
- 구조가 더 간단함
- 학습이 더 빠를 수 있음
- 성능은 LSTM과 비슷한 경우가 많음
```

코드에서는 이렇게 사용할 수 있다.

```python
tf.keras.layers.GRU(64)
```

---

## 10. LSTM과 GRU 중 무엇을 써야 할까?

처음에는 둘 다 사용해보고 결과를 비교하는 것이 좋다.

정답이 항상 정해져 있는 것은 아니다.

데이터에 따라 LSTM이 더 좋을 수도 있고, GRU가 더 좋을 수도 있다.

보통은 다음처럼 생각할 수 있다.

- 기억해야 할 정보가 길고 복잡하면 LSTM을 먼저 시도한다.
- 더 빠르고 단순한 모델을 원하면 GRU를 시도한다.
- 둘 중 무엇이 좋은지는 실제 데이터로 학습해보고 검증 성능을 비교한다.

---

## 11. 핵심 정리

- Simple RNN은 순서가 있는 데이터를 처리할 수 있다.
- 하지만 sequence가 길어지면 앞부분 정보를 잘 기억하지 못할 수 있다.
- 이 문제를 Diminishing Gradient 또는 기울기 소실 문제라고 부른다.
- LSTM은 긴 기억을 더 잘 유지하기 위해 만들어진 RNN 계열 모델이다.
- LSTM은 cell state와 gate를 사용한다.
- Forget Gate는 필요 없는 정보를 버린다.
- Input Gate는 새로 중요한 정보를 저장한다.
- Output Gate는 지금 필요한 정보를 출력한다.
- GRU는 LSTM보다 구조가 간단한 모델이다.
- LSTM과 GRU는 둘 다 써보고 성능을 비교하는 것이 좋다.
