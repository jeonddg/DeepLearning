# 01. 순서가 중요한 데이터는 어떻게 학습할까? (RNN 개념)

이번에는 **순서가 중요한 데이터**를 딥러닝이 어떻게 학습하는지 공부한다.

예를 들어 이런 문장이 있다고 해보자.

```text
I went to the library to ____
```

빈칸에 어떤 단어가 들어갈까?

사람은 앞에 나온 단어들을 순서대로 읽으면서 자연스럽게 다음 단어를 예상한다.

```text
I -> went -> to -> the -> library -> to -> ____
```

즉, 단어 하나만 보는 것이 아니라 **앞에서 어떤 단어들이 어떤 순서로 나왔는지**를 같이 본다.

---

## 1. 순서가 중요한 데이터란?

순서가 중요한 데이터는 데이터의 위치나 순서가 의미를 가지는 데이터이다.

예를 들어 다음과 같은 데이터가 있다.

- 문장: 단어의 순서가 바뀌면 뜻이 달라질 수 있음
- 주식 가격: 어제, 오늘, 내일 순서가 중요함
- 음성 데이터: 소리가 시간 순서대로 이어짐
- 날씨 데이터: 시간 흐름에 따라 변함
- 영상 데이터: 여러 장면이 순서대로 이어짐

이런 데이터를 보통 **Sequence 데이터**라고 부른다.

Sequence는 쉽게 말하면 **순서대로 이어진 데이터**이다.

---

## 2. Dense 모델만 쓰면 왜 부족할까?

지금까지 많이 사용했던 `Dense` 레이어는 입력 데이터를 한 번에 받아서 계산한다.

예를 들어 단어들을 그냥 하나의 입력으로 넣으면 모델은 다음처럼 볼 수 있다.

```text
[I, went, to, the, library, to]
```

문제는 Dense 레이어만 사용하면 **데이터가 어떤 순서로 들어왔는지 기억하기 어렵다**는 점이다.

문장에서는 순서가 매우 중요하다.

```text
I ate lunch
Lunch ate I
```

둘 다 같은 단어가 들어 있지만 의미는 완전히 다르다.

그래서 단어 예측, 번역, 감정 분석, 음성 인식처럼 순서가 중요한 문제에서는 일반 Dense 모델만으로는 부족할 수 있다.

---

## 3. 그래서 RNN이 등장했다

RNN은 **Recurrent Neural Network**의 줄임말이다.

한국어로는 보통 **순환 신경망**이라고 부른다.

RNN의 핵심 아이디어는 간단하다.

> 이전에 처리한 결과를 기억해두고, 다음 입력을 처리할 때 같이 사용한다.

예를 들어 문장을 단어 단위로 넣는다고 해보자.

```text
I -> went -> to -> the -> library -> to
```

RNN은 한 번에 모든 단어를 보는 것이 아니라, 단어를 순서대로 하나씩 처리한다.

```text
1. I를 입력한다.
2. I를 보고 나온 결과를 기억한다.
3. went를 입력할 때, 이전에 기억한 I의 정보도 같이 사용한다.
4. to를 입력할 때, 이전까지의 I went 정보도 같이 사용한다.
5. 이런 식으로 문장 끝까지 반복한다.
```

이렇게 하면 모델이 단어의 순서를 어느 정도 기억하면서 학습할 수 있다.

---

## 4. RNN은 무엇을 기억할까?

RNN이 이전 정보를 저장하는 값을 **hidden state**라고 한다.

hidden state는 쉽게 말하면 **지금까지 읽은 내용을 요약한 기억**이다.

예를 들어 `I went to the library`까지 읽었다면 hidden state 안에는 이런 정보가 들어간다고 생각하면 된다.

```text
지금까지 주어는 I였고,
went라는 행동이 나왔고,
library라는 장소가 나왔구나.
```

물론 실제로는 사람이 읽는 문장처럼 저장되는 것은 아니고, 숫자 벡터 형태로 저장된다.

하지만 개념적으로는 **이전 입력들의 요약 정보**라고 이해하면 된다.

---

## 5. RNN의 계산 흐름

RNN은 매 시점마다 두 가지를 사용한다.

```text
현재 입력 + 이전 hidden state
```

그리고 두 가지를 만들어낸다.

```text
현재 출력 + 새로운 hidden state
```

그림처럼 생각하면 된다.

```text
I 입력      -> RNN -> hidden state 1
went 입력   -> RNN -> hidden state 2
to 입력     -> RNN -> hidden state 3
library 입력 -> RNN -> hidden state 4
```

중요한 점은 hidden state가 계속 다음 단계로 전달된다는 것이다.

그래서 RNN은 이전 단어의 정보를 다음 단어 예측에 사용할 수 있다.

---

## 6. RNN으로 할 수 있는 일

RNN은 sequence 데이터를 입력으로 받을 수도 있고, sequence 데이터를 출력으로 만들 수도 있다.

대표적인 형태는 세 가지이다.

## 6-1. Sequence to Vector

순서가 있는 데이터를 입력받고, 하나의 결과를 출력한다.

```text
문장 전체 -> 긍정/부정
```

예시:

- 영화 리뷰 감정 분석
- 댓글이 악플인지 아닌지 판단
- 이메일이 스팸인지 아닌지 판단

입력은 여러 단어로 이루어진 문장이지만, 출력은 `긍정`, `부정` 같은 하나의 값입니다.

---

## 6-2. Vector to Sequence

하나의 입력을 보고 순서가 있는 데이터를 출력한다.

```text
이미지 한 장 -> 설명 문장
```

예시:

- 이미지 자동 캡션 생성
- 사진을 보고 “A dog is running” 같은 문장 만들기

입력은 이미지 하나지만, 출력은 여러 단어로 이루어진 문장이다.

---

## 6-3. Sequence to Sequence

순서가 있는 데이터를 입력받고, 순서가 있는 데이터를 출력한다.

```text
한국어 문장 -> 영어 문장
```

예시:

- 번역
- 챗봇 답변 생성
- 문장 요약

입력도 문장이고 출력도 문장이기 때문에 sequence to sequence라고 부른다.

이때 자주 나오는 개념이 **Encoder와 Decoder**입니다.

- Encoder: 입력 sequence를 읽고 중요한 정보를 요약함
- Decoder: 요약된 정보를 바탕으로 새로운 sequence를 만들어냄

---

## 7. RNN의 한계도 있다

RNN은 순서가 있는 데이터를 다루기 위해 만들어졌지만 단점도 있다.

문장이 짧을 때는 괜찮지만, 문장이 길어지면 앞부분 정보를 끝까지 잘 기억하기 어렵다.

예를 들어 아주 긴 문장에서 처음에 나온 주어를 마지막 단어 예측에 사용해야 한다면 RNN이 힘들어할 수 있다.

이 문제를 보완하기 위해 나온 모델이 다음과 같다.

- LSTM
- GRU

그리고 더 발전해서 요즘 많이 쓰이는 구조가 Transformer이다.

즉 흐름을 크게 보면 이렇게 이해하면 된다.

```text
Dense 모델
-> 순서 기억이 약함
-> RNN 등장
-> 긴 기억이 어려움
-> LSTM, GRU 등장
-> 더 발전해서 Transformer 등장
```

---

## 8. 핵심 정리

- Sequence 데이터는 순서가 중요한 데이터이다.
- 문장, 주식 가격, 음성, 날씨, 영상 등이 sequence 데이터이다.
- Dense 레이어만으로는 순서 정보를 기억하기 어렵다.
- RNN은 이전 결과를 다음 계산에 넘겨서 순서를 어느 정도 기억한다.
- RNN의 기억 역할을 하는 값을 hidden state라고 한다.
- RNN은 sequence to vector, vector to sequence, sequence to sequence 문제에 사용할 수 있다.
- 긴 문장을 기억하는 데는 한계가 있어서 LSTM, GRU 같은 모델이 등장했다.
